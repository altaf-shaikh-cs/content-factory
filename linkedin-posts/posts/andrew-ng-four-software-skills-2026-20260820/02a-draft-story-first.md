I used to think my job was building perfect software.

Clean code. Solid architecture. The stuff senior engineers get paid for.

Then I started using AI coding agents, and I noticed something. They lay the walls faster than I ever could.

That used to scare me. Now I think it just means I was measuring the wrong thing.

Andrew Ng went and analyzed 10,000 job postings to see which software skills actually matter in 2026. Four came back. Coding isn't one of them, but nothing on the list works without it.

1. Build and deploy AI apps, which means controlling something that gives you two different answers to the same question.
2. Software fundamentals, because every AI decision is a tradeoff it makes for you, quietly.
3. Use coding agents well. Know their limits. One bad instruction can wipe a production database.
4. Shape the build. Decide which problem is worth solving in the first place.

You're not the bricklayer anymore. The robot lays bricks now.

Of the four, which one are you actually building, and which one are you just hoping the agent handles for you?
