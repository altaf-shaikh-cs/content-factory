# Post Plan — anthropic-multi-agent-research-system

## Core Insight
Multi-agent is not a speed feature, it is a spending decision: you are buying each agent its own context window and paying about 15x the tokens for it, so the only real question is whether the task is worth that.

## Target Audience
Engineers in India's tech hubs who have already wired up one agent that works and are now being told to "add more agents." Software Engineer titles, 3-8 years in, early-to-mid career, currently deciding architecture without cost data.

## Structure
1. The two numbers together: 90.2% better answers, 15x the tokens. Neither means anything alone.
2. The reframe: subagents are not threads. What you buy is context isolation, not parallelism. Speed is a side effect.
3. What that tells you about when it pays: breadth-first work where workers never need to see each other's findings. Not coding, where they do.
4. The part nobody plans for: agents are stateful, so errors compound, and a dead agent looks exactly like a quiet one.

## CTA
Ask readers to name the last task they gave a single agent that came back mediocre, and whether they could write three non-overlapping briefs for it. Blog link goes in the first comment, never in the post body.

## Tone Range
Authoritative, with one honest builder admission. Peer to peer, not lecturing.

## Image Brief
Numbers to carry:
  - 90.2% — multi-agent (Opus 4 lead + Sonnet 4 workers) over single-agent Opus 4
  - 15x — tokens vs a chat interaction
  - 4x — tokens a single agent already uses vs chat
  - 80% — share of performance variance explained by token usage alone
  - 40% — drop in task completion time from rewriting tool descriptions
  - 90% — research time cut by parallel tool calling
Tagline: "Multi-agent buys context, not speed."
Before/after framing: one window shared by everything vs five windows, each thinking alone.

## Format
**text + image.** The account's only proven converting format (4.47% avg vs 0.70% for the one meme). Three document carousels are already built and none has ever shipped, so a fourth deck would add to unproven inventory instead of producing data. No meme this run either: the last three generated posts were carousels, not text, so the 1-in-4-5 reach budget is not due. Rationale: this idea is a decision rule, not a framework worth saving, and it fits in one screen.

## Performance Context
- Best performing angle so far: Contrarian, 7.43% (single post), then Story-first at 6.39% across two
- Best capture rate so far: none measured. The account's biggest post ever (parle-g meme, 4,113 reached) captured 0.00%
- Format trade: memes buy ~23x the impressions of a text post at ~1/6th the engagement rate and zero capture. Carousels are still completely untested here, three built and zero shipped
- Hook styles that drove comments: contrarian openings that name something the audience does but will not admit
- Hook styles that drove passive reactions only: observational humour, abstract process posts (routines, 2.48%)
- Topics/themes that resonated: practical skill-building, roadmaps, comparison framings where the reader picks a side in line one
- What to avoid repeating: leading with a scene instead of an uncomfortable truth. Also: no link in the post body, the link tax is still enforced
- Implication for THIS post: open with the number that makes the reader uncomfortable about their own architecture, not with the story. The seven-week outage is the proof in the middle, not the hook.

## Angle Assignments
Fixed angles:
  - Angle A: Story-first — open with the seven-week silence, let the insight about statefulness and monitoring emerge
  - Angle B: Bold claim-first — lead with "multi-agent is not a speed feature," back it with the token math

Angle C: **Data/number-first** — open with 90.2% and 15x side by side, let the text earn both.

Chose Data/number-first because decision rule 4 matched: this idea has a hero number (15x) that the image will carry, and putting two numbers in tension in line one is the comparison shape the tracker says top performers share. Rule 1 also technically matched (the seven-week outage is a genuine "I did not notice" admission), but that material is structurally where Angle A lands on this idea, so making it Angle C would have produced a near-duplicate rather than something the other two cannot.
