# Four software skills that matter in 2026 (Andrew Ng)

Source: a video/transcript (Hindi) summarizing Andrew Ng's take on what he found after analyzing 10,000 job postings to figure out which software skills matter in 2026. Coding still matters, but isn't itself one of the four standout skills — it's the prerequisite underneath all of them.

## Core framing

You used to be a bricklayer who built perfect walls. Now you have a robot (AI) that lays bricks faster than you. Your value is no longer in laying the bricks — it's in deciding where to build the wall and why. You're moving from laborer to architect.

## The four skills (per Andrew Ng)

1. **Building and deploying AI applications.**
   Obvious on the surface, but the real point: normal software is predictable, AI is not. Ask an AI model the same question twice and you can get two different answers. The skill isn't building AI — it's controlling that unpredictability. That means disciplined evaluation ("evals") and error analysis to measure and improve AI systems, not just shipping a demo and hoping.

2. **Software engineering fundamentals still matter — arguably more.**
   People assume that if AI is writing the code, fundamentals don't matter. Wrong. Every software decision is a tradeoff (fast vs. secure vs. cheap, etc.). You tell the AI "make it fast, secure, and cheap" — but you won't know what compromises it quietly made on your behalf, or what that costs you, if you don't understand fundamentals yourself. You'll only find out when things start breaking in production. Fundamentals are what let you catch the tradeoff before it becomes an incident.

3. **Using coding agents well.**
   Know what these agents are good at, where their limits are, and how much to trust them. One careless/wrong instruction to an agent can wipe out a production database. And you have to do all of this efficiently — how much time and how many tokens you burn to get something done matters as much as getting it done.

4. **Shaping what gets built.**
   You're no longer just an order-taker executing tickets. Part of the job now is deciding which problem is worth solving in the first place.

## Takeaway line

If you're learning AI, don't just learn to write code — learn to think like a senior engineer.
