## Banner Image Prompt

**Core metaphor:** A bricklayer's tools laid down beside a set of architectural blueprints, the trowel and level resting still while the drawing table is where the light and attention fall, capturing the shift from executing the work by hand to deciding what gets built.

**Prompt (universal base):**
Editorial illustration, minimalist and atmospheric, dark muted palette with a single warm amber accent light. A trowel and a mason's level rest in shadow on a stone ledge in the foreground, unused. In sharp focus behind them, an architect's drafting table holds an open blueprint sheet with abstract geometric line drawings, lit from above by a single hanging lamp. Sense of quiet transition, dusk light, negative space around the subjects, clean geometric composition, wide banner format, no visible text or characters.

**Tool modifiers:**
- Midjourney: append `--ar 16:9 --style raw --v 6`
- DALL·E / GPT-4o: add "digital illustration, flat design, no gradients"
- Ideogram: add "flat vector illustration, editorial style, tech blog"

**Do NOT include:** code on screens, company logos, text or titles, photorealism
